# CLAUDE.md — правила проекта для Claude Code

Курсовой проект «HSE AI Analytics» по ТЗ `docs/TZ_hackathon_HSE.docx`. Перед изменениями прочитай `README.md` и `docs/technical_documentation.md`.

## Принципы
- **Не отклоняться от ТЗ.** Новая функция должна закрывать конкретный пункт ТЗ (F-xx или MVP). Укажи его в коммите.
- **Один файл — одна задача.** Логика — в `src/`, связка — в `app/service.py`, HTTP — в `app/api.py`, UI — в `app/dashboard.py`. В дашборде расчётов нет.
- **Простота важнее сложности.** Автор должен уметь объяснить каждую строку на защите. Не добавлять Docker Compose, БД, React и прочее без явной просьбы.
- **Без утечки данных:** признаки риска — только лаги; для временных задач — разбиение по времени (`src/features.py`).
- Комментарии и docstring — на русском, коротко, с объяснением «почему».

## Команды
- Тесты: `pytest` (должны проходить перед каждым коммитом)
- Переобучить модели: `python -m src.train` (обновляет `models/` и `metadata.json`)
- API: `uvicorn app.api:app --reload`; дашборд: `streamlit run app/dashboard.py`
- Данные: `python data_generation/generate_data.py` (seed 42, результат детерминирован)

## Коммиты
Маленькие, по одному смысловому шагу. Формат: `feat(модуль): что сделано (F-xx)`, `fix: …`, `docs: …`, `test: …`.
